Appwrite is an open-source backend platform for web, mobile and AI applications, shipped both as a self-hostable BSD-3-Clause server and as the managed Appwrite Cloud. One REST API — 1,022 operations across 44 services in the published Appwrite 2.0 OpenAPI, mirrored field-for-field in GraphQL — covers authentication and user management, four database engines (TablesDB, DocumentsDB, VectorsDB and managed PostgreSQL, MySQL and MongoDB), file storage with an S3-compatible surface, serverless Functions, static and SSR Sites hosting, messaging, realtime presence over WebSocket, domains and DNS, backups and a WAF. Appwrite is unusually far forward on the agent layer: it serves an SEP-1649 MCP Server Card and a Domain AI Catalog from its own domain, runs a hosted OAuth-protected MCP endpoint at mcp.appwrite.io alongside a stdio server for self-hosted instances, publishes eleven Agent Skills through a machine-readable discovery index, and gives every documentation, blog and changelog page a Markdown twin.

**Areas:** Application · Backend · Mobile · Open Source · Database · Storage · Serverless · Authentication · Hosting · Agents

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Appwrite: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
